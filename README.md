# Jogo da Velha em JQuery

Este projeto foi desenvolvido durante um curso de desenvolvimento web na Udemy. O **Jogo da Velha** foi implementado utilizando a biblioteca JavaScript **jQuery**, com a possibilidade de jogar entre **2 jogadores**. Recentemente, a funcionalidade foi expandida para permitir também jogar **contra a I.A.** (Inteligência Artificial).

## Funcionalidades

- **Modo 2 Jogadores**: Permite que duas pessoas joguem localmente no mesmo dispositivo.
- **Modo contra a Máquina**: Agora, também é possível jogar contra a I.A. (Inteligência Artificial). A máquina faz jogadas automáticas, tornando o jogo mais desafiador para um único jogador.

## Tecnologias Utilizadas

- **HTML5**: Estruturação básica do jogo.
- **CSS3**: Estilização do layout e design do jogo.
- **jQuery**: Manipulação de DOM e controle da lógica de jogabilidade.
- **JavaScript**: Implementação da lógica do Jogo da Velha e da Inteligência Artificial.

## Como Usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/seu_usuario/Jogo_da_Velha_JQuery.git
   ```

2. Abra o arquivo `index.html` no seu navegador para jogar.

3. **Escolha o modo de jogo**:
   - **2 Jogadores**: Ideal para jogar com um amigo no mesmo dispositivo.
   - **Contra a Máquina**: Selecione esta opção para jogar contra a Inteligência Artificial.

4. Preencha os apelidos dos jogadores e clique em **Iniciar Jogo**.

5. Se estiver jogando contra a I.A., o computador fará suas jogadas automaticamente após você fazer a sua.
